# My_Startup_Project

Research notes and code for a question: can a small LLM keep learning from what it lives through
by consolidating each day into its weights at night (a "sleep" phase), instead of re-reading its
past in the prompt like RAG assistants do?

- [experiments/001-sleep](experiments/001-sleep/README.md): the first experiment, with results,
  failures and caveats. Phase 0 is closed; the result is a signal on 12 questions, not a proof.

Python 3.12, managed with [uv](https://docs.astral.sh/uv/); CPU only.
